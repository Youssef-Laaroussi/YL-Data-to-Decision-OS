## [0.1.0] - 2024-09-24

### Added
- **Core Architecture**: Modular Data-to-Decision pipeline linking Data Engineering, Data Quality, Analytics, ML Engineering, Decision Intelligence, and Feedback Loops.
- **Data Engineering**: Multi-source file ingestion (CSV, JSON), automated schema inspection, and ETL pipeline tracking.
- **Data Quality**: Data contracts validation, completeness and uniqueness audits, mixed-type detection, and IQR anomaly detection with quality gates.
- **Analytics & BI**: Descriptive statistics, quantile distributions, correlation analysis, and business KPI tracking with trend evaluation.
- **ML Engineering**: Scikit-Learn model training (Random Forest, Gradient Boosting, Linear Models), train/test split evaluation ($R^2$, RMSE, MAE), feature importance ranking, and artifact persistence.
- **Decision Engine**: Prescriptive decision rules engine transforming model predictions into actionable recommendations with confidence and ROI impact estimates.
- **Feedback Loop**: Post-decision measurement tracking expected vs actual outcomes, variance analysis, and continuous model improvement history.
- **Agentic AI**: Autonomous multi-stage orchestrator coordinating the entire pipeline lifecycle with complete audit logs.
- **Modern Web Interface**: React + Vite frontend with responsive navigation, interactive charts (Recharts), and execution console.
- **Open Source Documentation**: Architecture guides, API reference, pipeline concepts, and deployment manuals.
