# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

The Data-to-Decision OS team takes security seriously. If you discover a vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to `security@datatodecision.org` (or contact the repository maintainers directly).
3. Include:
   - A description of the vulnerability.
   - Steps to reproduce or a minimal proof of concept.
   - Potential impact.
4. We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.
5. Once resolved, we will publish a security advisory and credit you (if desired).
